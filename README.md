📌 Visão Geral

O PIG Bank é uma Single Page Application (SPA) que simula um ambiente de banco digital moderno, permitindo o gerenciamento de entradas e saídas financeiras de maneira dinâmica e intuitiva.

Mais do que apenas uma interface visual, o projeto foi estruturado para demonstrar competências relevantes no desenvolvimento Front-End moderno, incluindo:

organização de arquitetura
componentização
gerenciamento de estado
experiência do usuário
escalabilidade de código

A proposta é reproduzir padrões encontrados em aplicações reais do mercado financeiro, mantendo foco em performance, clareza visual e manutenção de longo prazo.

🎯 Objetivo do Projeto

O principal objetivo do PIG Bank é simular desafios comuns encontrados em aplicações financeiras modernas, trabalhando:

atualização dinâmica de informações
previsibilidade de comportamento
experiência do usuário
organização arquitetural
desenvolvimento orientado à escalabilidade

O projeto também funciona como demonstração prática de habilidades técnicas voltadas ao mercado Front-End.

⚙️ Como Executar
Clone o repositório
git clone https://github.com/Luizfelipeosz/PIG---BANK
Acesse a pasta
cd PIG---BANK
Instale as dependências
npm install
Execute o projeto
npm start
